README for kvadratka v11

Компилировать main.cpp желательно в более новом компиляторе (написано на g++ 26 года), остальные файлы просто пометить в одну папку с main.cpp.
Можно запускать уже собранный .exe файл.

Программа умеет решать квадратные уравнения. Есть 2 режима: пользовательский, в котором программа принимает 3 коэффициента и выводит решения
этого уравнения, а так же строит его график (который можно приближать или отдалять, а так же перемещаться стрелочками); тестовый, в котором
программа предлагает несколько опций (показывать или нет аргументы и решения в верных тестах (в неверных тестах всегда выводится), подключать
ли тесты из файла или в случае отказа запрашивает количество рандомных тестов, которые надо провести). Всё взаимодействие с пользователем
реализовано через различные меню. В случае неверного формата ввода программа укажет на это тем самым поможет пользователю в пользовании программой.
